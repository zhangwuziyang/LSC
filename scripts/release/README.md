# Assumption-Gated LLM Agents for Continuous-Treatment DID

Code, data generators, agent benchmark, run records and judgments for the paper
*Assumption-Gated LLM Agents for Continuous-Treatment Difference-in-Differences: An Application to E-commerce Delivery Times* (under review).

## Layout

| Path | Contents |
|---|---|
| `gpsdid/` | Estimators: normal and heteroskedastic gradient-boosting GPS, Hirano–Imbens two-step, cross-fitted doubly robust dose response with undersmoothing and subsampling variance inflation; diagnostics (balance, ESS overlap grades, placebo test, sensitivity); kink and gain matrix |
| `sim/` | Semi-synthetic data generator (`dgp.py`) and the agent benchmarks (`traps.py` pilot, `traps_v2.py` pre-registered 14-task benchmark) |
| `agent/` | Analysis session with gates G1–G5, semantic layer, LLM orchestrator (Anthropic-, OpenAI-compatible providers), code-writing baseline, fixed no-LLM workflow |
| `cases/olist.py` | Seller-month panel from the public Olist data |
| `experiments/` | One script per experiment, plus `results/` (all outputs used in the paper), `judging/` and `judging_v2/` (blinded items, rubrics, judgments, condition keys) |
| `docs/E2V2_PLAN.md` | Pre-registration of the E2 v2 benchmark, with the protocol amendments made before the affected runs or judging |
| `paper/latex/` | Paper source |

## Install and test

```bash
pip install -e ".[dev]"          # add ".[agent]" to run LLM experiments
pytest -q
```

## Reproduce

Simulation experiments need no API access; times are for one CPU core.

```bash
python experiments/e1_estimators.py --reps 20 --n 20000                  # E1 (Table 2, Fig. 2)
python -m experiments.e1b_robustness --scenario gamma --reps 15          # E1b; scenarios: bimodal, gamma,
                                                                         #   strong_confounding, n5k, n50k
python experiments/e2a_placebo_gate.py                                   # E2a (Fig. 3)
git clone --depth 1 https://github.com/olist/work-at-olist-data ../olist-data
python experiments/e3_olist.py --data ../olist-data/datasets             # case study (Fig. 4)
```

E2b (agent benchmark). Copy `.env.example` to `.env` and set the provider keys.

```bash
python -m experiments.e2v2_reference --reps 3                            # ground truth per dataset
python -m experiments.e2v2 --condition fixed --reps 3                    # fixed workflow (no API)
python -m experiments.e2v2 --condition full --provider deepseek --reps 3 --skip-done
#   conditions: full, no_gates, code; providers: deepseek, qwen
python -m experiments.judge_export_v2 --key key.csv                      # blinded items for judging
python -m experiments.e2v2_analyze --key experiments/judging_v2/key_v2.csv \
    --judges experiments/judging_v2/judgments_A.csv experiments/judging_v2/judgments_B.csv \
    --arbiter experiments/judging_v2/judgments_C.csv                     # Table 4 and paired tests
```

LLM runs are not deterministic; the records used in the paper are in `experiments/results/e2v2/`.
Commit hashes cited in `docs/E2V2_PLAN.md` refer to the development repository.

## Data

The semi-synthetic data are generated by `sim/dgp.py`. The Olist data are public under the MIT licence and are downloaded separately (see above). No proprietary data are included.
