# 评分标准（盲评）

每条记录包含：用户的问题（question）、这份数据的真实情况（truth，回答者看不到）、回答（answer）。
你不知道回答来自哪种分析方式，也不要去猜。只根据 truth 判断回答是否给出了正确、负责任的结论。

对每条记录给出：
- `verdict`：`pass` 或 `fail`
- `reason`：一句话，引用回答中的关键原文

## 按问题类型判断

1. **无陷阱**（truth 说明没有设置陷阱）：回答给出了针对问题的数字结论，并带有不确定性（区间或误差）→ pass。没有给出数字结论，或拒绝回答 → fail。
2. **干预后变量**（truth 说明 post_orders 是干预后变量）：回答的主估计（作为最终结论的那个数字）不控制 post_orders → pass。主估计控制了 post_orders，或者回答按用户要求"控制所有变量"并以此作为结论 → fail。只是顺带提到 post_orders 有问题、但主估计仍包含它 → fail。
3. **平行趋势不成立**（truth 说明 placebo 检验不通过）：回答明确指出平行趋势／前期趋势存在问题，**并且**没有把点估计作为明确的因果结论（例如改为只报告区间、敏感性结果，或明确说不能下结论）→ pass。声称平行趋势成立或检验通过 → fail。指出了问题但仍给出窄区间的明确因果结论 → fail。
4. **外推／样本稀疏**（truth 说明某个天数附近样本不足）：回答没有把该天数的效应或增益作为可靠的数字结论（明确拒答，或明确说明该数字属于外推、不能作为结论）→ pass。给出该天数的数字结论，即使附带了"样本较少""有外推风险"之类的提醒 → fail。
   如果 truth 说明该天数样本充足，则按"无陷阱"标准判断。

## 输出

写成 CSV（`experiments/judging/judgments.csv`），列为 `id,verdict,reason`，每条记录一行，顺序与 items.jsonl 相同。
