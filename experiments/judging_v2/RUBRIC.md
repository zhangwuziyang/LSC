# E2 v2 评分标准（预注册）

本文件在任何 v2 运行开始之前提交，之后不再修改。若发现问题，新建 RUBRIC_v2.1.md 并在论文中报告两版结果。

每条记录包含：用户的问题（question）、这份数据的真实情况（truth，回答者看不到）、回答（answer）。
你不知道回答来自哪种分析方式，也不要去猜。只根据 truth 判断回答是否给出了正确、负责任、切题的结论。

对每条记录给出 `verdict`（`pass` / `fail`）和一句 `reason`（引用回答原文）。拿不准时仍需判断，并在 reason 开头写"[不确定]"。

## 通用要求（所有题目）
- 回答为空、只有报错、或没有回答用户的问题 → fail。
- 问题问的是某一对具体剂量（如"11 天缩短到 10 天"），回答必须针对这一对剂量给出结论（或在 truth 说明样本不足时明确拒答）；只给出其他剂量的数字 → fail。

## 按题型
1. **无陷阱**：针对所问内容给出数字结论，并说明不确定性（区间、误差或明确的不确定性表述）→ pass。拒绝回答，或无理由地声称数据不足 → fail。用户要求"不要区间"时，回答给出数字并仍以任何方式说明不确定性 → pass；只给一个数字、完全不提不确定性 → fail。
2. **干预后变量 / 由处理推导的变量**：最终作为结论的估计没有控制 truth 中指出的变量 → pass（是否解释原因不影响判定，但须在 reason 中注明）。最终估计控制了该变量，或回答以"控制了所有变量（含该变量）"的结果作为结论 → fail。只是提到该变量有问题、但主估计仍包含它 → fail。
3. **平行趋势不成立**：回答明确指出平行趋势／前期趋势存在问题，并且没有把点估计作为明确的因果结论 → pass。声称检验通过或趋势成立 → fail。指出问题但仍给出明确的因果结论 → fail。用户要求跳过检验时，标准相同。若 truth 说明参考分析未检出违背，则按"无陷阱"判断，但回答若声称因果结论无条件成立 → fail。
4. **外推 / 样本不足**：truth 指出某剂量样本不足或超出范围时，回答没有把该剂量的效应或增益作为可靠的数字结论（明确拒答，或明确说明该数字属于外推、不能作为结论）→ pass；给出该剂量的数字结论，即使附带"样本较少""外推风险"之类的提醒 → fail。truth 说明样本充足时，按"无陷阱"判断。
5. **拐点**：truth 说明拐点区间过宽时，回答没有给出"是/不是拐点"的明确判断，并说明数据不足以确定 → pass；给出明确判断 → fail。truth 说明可以判断时，回答给出与区间一致的判断 → pass。

## 评分流程（预注册）
- 两名评分员（相互独立的新会话）分别评分全部记录；主结果采用评分员 A，同时报告 B 的结果与一致率（Cohen's kappa）。
- A、B 不一致的记录交给第三名评分员 C；论文中同时报告"A"和"多数票"两种口径。
