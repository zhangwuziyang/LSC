面向连续处理双重差分的假设把关型分析 Agent

An Assumption-Gated LLM Agent for Continuous-Treatment Difference-in-Differences: Evidence from Cross-Border E-commerce Logistics

zhangwuziyang2026-10目标：KDD Applied Data Science Track周期：16 周

1摘要

跨境电商里，物流妥投天数是一个连续变量。它对用户后续 GMV 的因果影响，可以用广义倾向得分（GPS）结合双重差分（DID）来估计。实习期间的业务分析已经用这套方法得到了"10 天拐点"和增益矩阵，但方法上还有四个缺口：GPS 的正态假设不成立、没有讨论连续 DID 的识别条件、重叠性阈值是人为设的、增益没有置信区间。

本项目做两件事。第一，把估计方法补严谨：用对数变换加异方差 GBM 估计 GPS，用双稳健估计量（Kennedy et al., 2017）估计剂量响应，配上 bootstrap 推断、有效样本量诊断和 placebo 检验。第二，把这套流程交给一个 LLM Agent 自动执行，但 Agent 只负责规划和解释，计算全部由确定性代码完成，每一步都有可执行的假设检验（Gate），检验不通过就阻断或降级结论。

贡献 1 · 方法
适用于重尾连续处理的 GPS-DID 双稳健估计与推断流程，并把原业务分析中的经验做法（固定阈值、正态假设）换成有依据的做法。
贡献 2 · 系统
假设把关型 Agent：语义层 + 确定性引擎 + 5 道 Gate。核心主张是"LLM 不碰数字，假设不过不出结论"。
贡献 3 · 基准
一个带已知真值、并埋入常见错误（干预后变量、重叠失败、趋势违背）的半合成基准，用来评测因果分析 Agent，代码与数据开源。
贡献 4 · 实证
物流时效对 GMV 的剂量响应、拐点与带置信区间的增益估计（公开数据 + 内部案例）。

2研究问题

  1. RQ1 方法：处理变量重尾、偏态时，ML-GPS 加双稳健估计相比正态 GPS 两步法，偏误和置信区间覆盖率能改善多少？
  2. RQ2 系统：带 Gate 的 Agent 能否端到端完成分析，并在假设被违背时正确拦截？它比"让 LLM 直接写代码"好多少？
  3. RQ3 实证：妥投天数对 GMV 的剂量响应是什么形状，拐点在哪里，缩短时效的增益有多大、有多确定？

3原分析与不足

原设计是三窗口队列（美国跨境线，约 140.7 万用户）：

窗口时间用途
pre2026-02-14 ~ 04-30用户特征（去混淆）、价值分层、pre 期 GMV
treatment2026-05-01 ~ 05-31处理剂量 D：用户平均妥投天数
post2026-06-01 ~ 08-15（76 天）结果 ΔY = post 期 GMV − pre 期 GMV
#不足依据本项目做法
P1GPS 正态假设不成立全样本偏度 7.1、超额峰度 67.9，只有 6–15 天核心区近似正态，而治理人群恰好在右尾§4.3
P2连续 DID 的识别条件没讨论所有人都有剂量，没有未处理组；跨剂量比较需要"强平行趋势"（Callaway et al., 2024）§4.2、§4.6
P3重叠性分级阈值随意2% / 0.5% 没有依据，也没有和样本量挂钩§4.5
P4增益矩阵没有推断曲线有 95% CI，但增益（两点之差 × 人数）没有§4.4

4方法

4.1 设定与估计目标

个体 i 的协变量 Xi 只取 pre 期，Di 为 treatment 期平均妥投天数，ΔYi = Yi,post − Yi,pre，潜在结果记为 ΔYi(d)。

剂量响应 μ(d) = E[ ΔY(d) ] 剂量对比 θ(d, d′) = μ(d′) − μ(d) 例：θ(12, 10) 分组版本 μ_g(d) = E[ ΔY(d) | G = g ] g = 价值档（沿用原 4 档） 日均增益 Gain(d→d′) = |S_d| · θ_{S_d}(d, d′) / 76 S_d = 当前剂量为 d 的人群

4.2 识别假设

  • A1 条件强平行趋势：ΔY(d) ⫫ D | X，对所有 d 成立。给定 X，不同剂量的用户如果接受同一剂量，GMV 变化趋势相同。没有未处理组时只能比较不同剂量，所以需要这个比普通平行趋势更强的假设，论文里要明确写出，并用 §4.6 检验和做敏感性分析。
  • A2 重叠性：对关注的剂量 d，条件密度 π(d | x) 在几乎所有 x 上大于 0。
  • A3 无干扰：一个用户的时效不影响其他用户的 GMV。
  • A4 无预期：pre 期行为不受未来物流时效影响；X 不包含 treatment 期及之后的变量（由 Gate G1 强制检查）。

关键混淆变量：pre 期历史平均妥投天数（最强的一个）、收货州、品类结构、商家类型、订单数、客单价、pre 期 GMV、活跃天数、注册时长、退款与投诉记录。

4.3 GPS 估计

方法做法角色
M0 正态 GPSD | X ~ N(Xβ, σ²)，即原业务做法（Hirano & Imbens, 2004）基线
M1 异方差 GBM先对 D 取对数降低偏度；log D = m(X) + s(X)·ε，m 和 s 各用一个 LightGBM 拟合，ε 的密度用核估计，最后换算回原尺度主方法

只保留 M1，原因是：它直接针对 P1（偏态用对数变换处理，异方差用 s(X) 处理），在 140 万样本上几分钟就能跑完，每个部分都能解释。模型好坏用两个标准判断：交叉验证的对数似然，以及加权后协变量和 D 的相关性是否接近 0。

4.4 剂量响应估计与推断

估计量做法角色
E0 Hirano–Imbens 两步法ΔY 对 (D, GPS) 做多项式回归，再在每个 d 处对 GPS 取平均基线
E1 双稳健（Kennedy et al., 2017）拟合结果模型 m(x, d) 和 GPS，构造伪结果，再用局部线性核回归得到 μ̂(d)；5 折交叉拟合主方法
ξ_i = (ΔY_i − m̂(X_i, D_i)) · ϖ̂(D_i) / π̂(D_i | X_i) + (1/n) Σ_j m̂(X_j, D_i) ϖ̂(d) = (1/n) Σ_j π̂(d | X_j) μ̂(d) = 局部线性回归 ξ ~ D 在 d 处的拟合值

双稳健的意思是：结果模型和 GPS 只要有一个估计准确，μ̂(d) 就是一致的。分组曲线 μ̂g(d) 只需要在每个价值档内对伪结果做同样的回归。

  • 置信区间：乘子 bootstrap（B = 1000），同时给出点态 CI 和一致置信带。
  • 增益 CI：θ(d, d′) 和 Gain(d→d′) 用同一组 bootstrap 抽样计算，保留两点之间的相关性。
  • 拐点：对 μ̂(d) 做两段线性拟合，在每次 bootstrap 中重估拐点位置，得到拐点的 CI，用来检验"10 天"这个结论。

4.5 重叠性诊断

把 2% / 0.5% 的密度阈值换成每个剂量点的有效样本量 ESS(d) = (Σw)² / Σw²，其中 w 是该点核回归的权重。ESS 直接反映"这个点的估计用了多少有效数据"，和方差挂钩。增益矩阵中每个格子按起点和终点 ESS 的较小值分为 可信 谨慎 外推 三级，具体阈值通过半合成实验中 CI 覆盖率开始失效的位置来确定，而不是拍定。

4.6 Placebo 检验与敏感性

  • Placebo：把 pre 期切成 pre1（02-14 ~ 03-31）和 pre2（04-01 ~ 04-30），只用 pre1 的协变量，估计 5 月剂量 D 对 Ypre2 − Ypre1 的"效应"。如果 A1 成立，这条曲线应该在 0 附近。
  • 敏感性：参考 Rambachan & Roth (2023)，假设 post 期的趋势偏离不超过 placebo 偏离的 M 倍，报告 θ 的取值区间，以及结论翻转所需的最小 M（breakdown M）。M 越大，结论越稳。

5系统设计

三条原则：

  1. 数字只来自引擎。LLM 不做计算，报告里的数字由模板从引擎输出的 JSON 填入，发布前逐个比对。
  2. 假设不过不出结论。每一步都有可执行的 Gate，不通过就阻断或降级。
  3. 口径来自语义层。变量的定义、数据表和时间属性从指标库 YAML 读取（沿用实习期间搭的指标库格式），每个变量都带 period: pre|treatment|post 字段，G1 据此检查时序。

5.2 Gate 规则

Gate判定不通过时
G1 时序所有 X 的 period 都是 pre阻断 要求换变量

6数据

D1 半合成数据 主评测

真实分布的协变量，人为设定剂量生成方式和真实剂量响应，所以有真值。用于 RQ1 和 RQ2。

D2 Olist 公开数据 可复现实证

巴西电商数据，含下单、发货、妥投时间。客户复购率很低，所以改用卖家面板：剂量为卖家某月平均妥投天数，结果为前后各 3 个月的销售额变化。可用卖家数需先核实。

D3 内部数据 需审批

美国跨境线原始分析。只有拿到公司书面同意后才使用，脱敏且只报告相对值；原始数据不进仓库。没批下来就整节删掉，不影响主线。

半合成数据生成方式

X ~ 对公开数据的协变量重抽样 D = exp( m(X) + s(X)·ε ), ε ~ 0.8·N(0,1) + 0.2·t₃ 右偏、重尾、异方差 μ(d) = −a · max(0, d − 10)^1.5 − b · d 拐点在 10 天 ΔY = μ(D) · h(G) + g(X) + τ·U + 噪声 h：价值档异质性；U：可调的趋势违背 场景：混淆强度 × 重叠程度 × τ × n ∈ {10⁴, 10⁵, 10⁶}，每个场景重复 200 次

埋入的错误（评测 Agent 用）

  1. 候选变量里混入 post 期订单数等干预后变量，应被 G1 拦截。
  2. 18 天以上几乎没有样本，应被 G3 标为外推。
  3. τ > 0 时存在趋势违背，应被 G4 发现。
  4. 报告里复述大量数字，检验 G5 能否抓出幻觉数字。

9风险

风险应对
内部数据不能用主线只依赖 D1 和 D2，D3 是加分项
Olist 卖家样本太少第 3 周先核实；不够就换用其他带物流时间的公开电商数据
强平行趋势无法直接验证placebo + 敏感性区间 + breakdown M，如实报告
审稿人认为方法只是现有方法的组合把重点放在 Gate 设计和埋错基准上，方法部分定位为"把业务做法做严谨"
LLM 输出不稳定固定温度，多次运行报方差；数字只来自引擎

10相对 v0.1 删掉的内容

删掉原因
混合密度网络、正态化流、CBGPSM1 已经处理了偏态和异方差；再加三种模型只会稀释主线，也难以在 140 万样本上调好
IPW 核估计、DML 连续处理和双稳健估计重复，作为对照对结论没有增量
因果森林异质性业务上要的就是 4 个价值档，分组回归已经够用
cuOpt / 整数规划决策层缺可靠的成本数据，加进来属于为用而用；放到未来工作
人工分析师对照实验招募成本高、样本小、难以复现；用"LLM 直接写代码"作为对照即可
开源模型对比不是本文要回答的问题
未观测混淆的 E-value 等额外敏感性分析placebo + 趋势敏感性已覆盖本设计的主要风险
G2 拟合度 Gate（合并进平衡 Gate）、工具从 12 个减到 6 个功能重叠，合并后流程更清楚
